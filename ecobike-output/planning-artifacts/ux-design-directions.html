Principios Liquid Glass para EcoBike
El mapa nunca se oculta
Toda la UI flota sobre el mapa. No hay pantallas que lo tapen — el mapa es el lienzo permanente.
Superficies adaptativas
El tinte de las superficies de vidrio cambia segun el contenido del mapa debajo (verde en zonas verdes, mas neutro en avenidas).
Jerarquia por profundidad
Los elementos mas importantes tienen mas blur y menos transparencia. Los secundarios son mas translucidos.
Implementacion: Expo Blur
expo-blur + BlurView para iOS/Android. backdrop-filter:blur() para web. Fallback opaco en dispositivos sin soporte.
