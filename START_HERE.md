# 🎉 EcoBike - React Web Edition

**¡Tu aplicación EcoBike ha sido exitosamente convertida de React Native a React Web!**

## ⚡ START HERE (Empieza aquí)

### 4 Pasos para Publicar:

```bash
# 1. Configura Firebase
cp .env.example .env.local
# Edita .env.local con tus credenciales

# 2. Instala dependencias (ya hecho ✅)
npm install --legacy-peer-deps

# 3. Prueba localmente
npm start
# Abre http://localhost:3000

# 4. Publica en GitHub Pages
npm run deploy
# Tu app estará en: https://TU_USUARIO.github.io/EcoBike
```
